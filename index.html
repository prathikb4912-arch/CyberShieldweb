Recent awareness tips

🛡 AI Scam Detector WORKING · RULE-BASED

Paste a suspicious SMS, WhatsApp message, email or online offer.

🔒 Never paste passwords, OTPs, PINs or card numbers. Emails, phone numbers and long digit strings are masked automatically before analysis. Analysis happens entirely in your browser; nothing is sent anywhere.

This tool uses keyword and pattern rules, not a language model. A server-side AI API (key kept on the server) is the planned next step and is not connected.

🔗 Smart Link Scanner BASIC CHECKS

Enter a web address. Do not open suspicious links to “test” them.

NOT CONNECTED Known-malicious-site databases (such as Google Safe Browsing or VirusTotal) need a server-side API key. None is connected, so no reputation lookup is performed.

📞 Number Intelligence FORMAT VALIDATION

Check whether a phone number matches an international numbering plan. This does not identify the owner or prove whether a caller is trustworthy.

REPUTATION NOT CONNECTED This upgrade checks number structure using a phone-number metadata library when internet access is available. It does not query spam reports, carrier records, or identify a private person. A reputation API and secure server backend would be needed for that.

Cyber Safety Tips

📣 Report a Scam NO SUBMISSION BACKEND

Reports cannot be submitted to CyberShield yet. This tool prepares a cleaned report you can copy and send to your bank, your mobile carrier or your national fraud-reporting service.

Deleting a report: nothing is stored, so there is nothing to delete. A deletion option will be added if server storage is ever built.

Privacy Policy & Protection

  • We never ask for passwords, OTPs or banking PINs. If a CyberShield page seems to, close it.
  • Current handling: text you enter is processed in your browser and is not sent to a server, stored or shared by this prototype.
  • Masking: emails, phone numbers, long digit strings and OTP-style codes are replaced with placeholders before analysis.
  • Deletion: there are no stored reports to delete. If a backend is added, this page will describe what is stored, for how long, and how to delete it.
  • Future AI analysis: if an external AI or threat-intelligence API is connected, this policy must be updated to say what is sent to it.

This is a prototype policy and not legal advice.
